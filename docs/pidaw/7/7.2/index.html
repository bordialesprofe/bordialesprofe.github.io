7.2 Recursos prácticos para la memoria y la defensa

En este apartado se incluyen materiales de apoyo para elaborar la memoria final y preparar la exposición del proyecto. Estos recursos no sustituyen a la plantilla ni al índice oficial de la memoria, sino que sirven como ayuda práctica para entender cómo desarrollar cada apartado, cómo presentar ejemplos y cómo organizar la defensa oral.

Los materiales utilizan como referencia un proyecto ficticio llamado GreenMarket, una aplicación web orientada a conectar consumidores interesados en productos ecológicos de proximidad con productores locales. El ejemplo incluye funcionalidades como la consulta de productos, el filtrado por categorías, la visualización del detalle de producto, el carrito y el contacto con vendedores.

Los ejemplos incluidos son modelos reducidos y orientativos. No están desarrollados al 100%, ni deben copiarse literalmente, sino que sirven para mostrar el nivel de explicación esperado, el tipo de tablas o diagramas que pueden incluirse y la forma de relacionar cada apartado con el proyecto.

1️⃣ Guía práctica para elaborar la memoria final​

Este documento recoge orientaciones y ejemplos aplicados al proyecto ficticio GreenMarket para desarrollar la memoria final. Su finalidad es ayudar a redactar cada apartado con mayor claridad, evitando limitarse a completar la plantilla con frases breves o información poco desarrollada.

2️⃣ Presentación de apoyo: elaboración de la memoria final​

Esta presentación explica de forma visual cómo puede desarrollarse cada apartado de la memoria final. Incluye ejemplos reducidos aplicados a GreenMarket, recomendaciones sobre diagramas, tablas, capturas, pruebas, despliegue y anexos, para que el alumnado tenga una referencia práctica del nivel de detalle esperado.

3️⃣ Presentación de apoyo: defensa del proyecto final​

Esta presentación sirve como modelo para preparar la exposición oral del proyecto. Utiliza GreenMarket como ejemplo orientativo y plantea una estructura posible para una defensa de 10-12 minutos, centrada en la idea del proyecto, la justificación, la arquitectura, las tecnologías, las funcionalidades implementadas, la demo, las pruebas, el despliegue y las conclusiones.
